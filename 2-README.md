# EL COMMANDER

Prototipo mobile-first de una sala de lectura: COACH, MARIE, JUAN, MACA y PETER.

HTML, CSS y JavaScript sin dependencias. Abrir index.html, o servir la carpeta con cualquier servidor estático. GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).

## Qué funciona

- Navegación entre las cinco pestañas, enlaces por hash y volver/avanzar del navegador.
- COACH: devolución desplegable, borradores de misión en memoria, eliminación y copia para pegar en el chat.
- MARIE: propuesta desplegable.
- JUAN: filtros y lectura de tarjetas.
- MACA: resumen, conexiones y preguntas de ejemplo.
- PETER: controles sobre una ilustración CSS.

## Límites

Todo el contenido está marcado como ejemplo. No hay conexiones a WhatsApp, agentes, Drive, archivos, noticias, libros ni fotos. Los borradores no se envían, no se guardan al cerrar la página y no se sincronizan. La vista de PETER no es un LUT. Ninguna tarjeta representa tareas reales en ejecución. No contiene conversaciones ni archivos personales.
